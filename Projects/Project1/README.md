# Project 1

Software has a major impact across nearly every area of our lives. To that end, the goal for this CS3704 project will be to work collaboratively to develop a software project. You may build whatever you want, as long as the project involves developing a software system and every student works with at least one other person.

**Learning Outcomes:**
> * Use AI tools to generate code~~, unit tests, and test suites; evaluate the quality and accuracy of AI-generated artifacts; and refine outputs to meet functional, performance, and quality requirements.~~
> * Create and communicate (via demo and writing) about the requirements and design of a software application.

The goal of this project is to gain practical experience working on a software project in a team setting.

## Guidelines

Your project must aim to solve a real-world problem. You are free to satisfy this goal however you wish. For this assignment, students:

* Must implement a software system;
* Must use a (public) GitHub repository;
* Must complete assigned project milestone deliverables (see below);
* Must complete a demo presentation of the implemented system;
* Must work in a group (choose your own team);
* May use Generative AI tools to support implementation (adhering to the class [AI Policy](../../AI_POLICY.md) and your team's specific policy).

### Teams

Work must be equally divided among the team members. All groups will construct a team policy outlining team meeting preferences, AI usage, etc. Each member of the team must adhere to this policy for the duration of the project.

### Technology

All projects should be maintained in a public [GitHub](https://github.com) repository. To track work, teams should utilize task management (i.e. GitHub projects) and/or issue tracking (i.e. GitHub issues) on GitHub. Opencode must be used for agentic development. Otherwise, you may use any programming languages, frameworks, etc. to implement your system.
